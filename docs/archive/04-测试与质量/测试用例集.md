# 04 · 测试用例集

> UAE Match ｜ 版本 v1.0.0 ｜ 更新 2026-07-04

本用例集按功能模块组织，覆盖 UAE Match v1.0.0 的核心接口与算法。每模块含正例（正常流程）与反例（边界/异常）。所有接口默认前缀 `/api/v1`，除标注外均需 `Authorization: Bearer <access_token>`。

**用例 ID 规约**：`TC-<模块码>-<序号>`。模块码：AUTH 认证 / PROF 资料偏好 / PHOTO 照片 / AIREG AI引导注册 / MATCH 匹配 / INSIGHT AI匹配分析 / CHAT 聊天 / AICHAT AI红娘 / SAFE 安全风控 / PAY 支付订阅 / QUOTA 配额预算 / ADMIN 管理后台。
**优先级**：P0 致命核心 / P1 严重 / P2 一般 / P3 轻微。
