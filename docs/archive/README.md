## 这是什么

本目录下的所有文档（`00-项目管理` ~ `07-运营与增长`）是接手初期、**在尚未获知权威规格文档存在时**，基于 **v1.0 代码现状**自动生成的一批文档。它们描述的是当时代码的样子：**滑动式匹配、人民币道具变现、滚动摘要记忆**等。

## 为什么归档

这批文档与项目的**权威规格**方向存在**根本冲突**：

| 维度 | 本目录旧文档（v1.0 代码） | 权威规格（BRD v2.1 / PRD v1.1） |
|---|---|---|
| 匹配 | 滑动 / 每日推荐 / like-pass | 稀缺推荐信制，无滑动 |
| 变现 | 人民币道具（Boost/超级喜欢等） | AED 订阅四层，道具冻结 |
| 记忆 | 滚动摘要 | 事实/事件/情感三层双轨 |
| 信任 | 10 秒自动过审（演示态） | EID 核验 + 深访 + 付费三道闸 |
