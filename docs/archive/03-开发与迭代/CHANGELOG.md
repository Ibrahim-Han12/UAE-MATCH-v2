## [Unreleased] · 规划中

> 对应产品路线图**第一阶段 · 商业化闭环（里程碑 M1，Sprint 1–4）**。

### 新增(Added)
- **支付网关真实对接**：接入真实支付渠道（支付宝 / 微信 / Stripe 信用卡至少一条），打通下单 → 跳转 → 回调 → 订单/订阅落库完整链路。
- **订阅自动续费**：`auto_renew` 与 `next_billing_date` 真实生效，到期扣费与降级。
- **增值服务下单**：超级喜欢 / Boost / 查看谁喜欢我 的真实购买与即时到账。
- **通知系统**：从桩实现补全为存储 + 站内通知（新匹配 / 新消息 / 被喜欢 / 订阅到期），Web Push 作为延伸。
- **通知偏好设置**：用户可配置接收的通知类型（防打扰）。
- **会员中心**：前端展示当前订阅计划、到期日与剩余额度。

### 变更(Changed)
- **会员权益授权模型**：VIP / 会员权益判定由前端硬编码开关改为**服务端订阅状态授权**；basic / premium 额度与特权按订阅真实差异化生效。
- **照片流程转真实态**：移除"注册后 10 秒自动过审"演示逻辑，改为真实审核态（后台人工/规则审核）。
- **编辑资料转真实态**：前端改为真实调用 `PUT /profile/me`，去除 mock 兜底数据。

### 修复(Fixed)
- 支付回调**幂等处理**：重复回调不重复入账、不重复发放权益。
- 支付失败 / 超时的订单状态处理与前端反馈缺失问题。

### 安全(Security)
- **JWT 密钥治理**：双密钥（访问/刷新）改为强随机并从环境变量注入，移除默认/明文密钥。
- **OpenAI API Key 轮换**：Key 走环境变量 / 密钥管理，历史可能泄露的 Key 作废；密钥不再进入代码库。
- **支付回调验签**：对支付渠道回调做签名校验，防伪造回调。

## [1.0.0] · 2026-07-04 · 已发布

首个功能骨架版本：端到端全栈骨架完成，验证 **AI 语义匹配 + AI 红娘"小缘"** 的可行性，可本地运行全链路。已在 GitHub 打 `v1.0.0` tag。

### 新增(Added)
- **全栈项目骨架**：后端 FastAPI + SQLite（约 58 接口 / 20 张表），前端 React + Vite；本地可跑通"AI 引导注册 → 向量匹配 → 互相喜欢 → 聊天 → AI 红娘"全链路。
- **账户与认证**：邮箱/手机 + 密码注册登录，JWT 访问令牌与刷新令牌。
- **个人资料与照片**：资料增改查、择偶偏好、扩展信息（兴趣/价值观）；照片上传（≤9 张）、排序、设主图、删除、审核状态字段（后端完整）。
- **AI 引导注册**：AI 红娘"小缘"对话式收集资料，抽取结构化数据落库并生成向量。
- **AI 智能匹配**：规则匹配 + AI 向量语义匹配（余弦相似度）双策略；喜欢/跳过/超级喜欢、互相喜欢自动配对、谁喜欢我。
- **AI 匹配分析报告**：为指定对象生成兼容性分析 + 破冰开场白（带缓存）。
- **实时聊天**：WebSocket 实时消息 + REST 历史消息、已读状态。
- **AI 红娘咨询**：日常对话咨询、长期记忆（滚动摘要）、个性化风格；VIP 主动关怀（定时 + 事件触发，含防打扰）。
- **安全与风控**：内容审核（关键词/正则）、拉黑、举报、限流、事件日志（event_logs）。
- **支付与订阅框架**：下单、支付回调、订单/订阅管理、商品目录（basic/premium 月付年付、super_like、boost、who_liked_me）——**框架完整，未接真实网关**。
- **管理后台**：举报处理、风险事件查看、统计看板。
- **数据分析**：用户快照统计（analytics），为 AI 提供匹配上下文。
- **文档体系**：BRD / HLD / LLD 及项目管理文档，完成文档与代码一致性清理与目录规整。

### 已知限制(Known Limitations)
- 💰 **支付未接真实网关**：下单/回调/订阅逻辑具备，缺真实渠道对接与验签。
- 🔴 **通知系统为桩实现**：接口返回空数据。
- 🧪 **前端存在演示态**：注册后 10 秒自动过审、VIP 为前端开关、部分页面 mock 兜底、编辑资料未完全打通。
- 🔐 **安全基线待加固**：JWT/OpenAI 密钥需改为强随机并走环境变量。
- 🗄️ **数据库为 SQLite**：仅限开发，生产需迁移 PostgreSQL + pgvector。
- 🌍 **仅中文**：多语言（英语/阿语）未做。
- 📱 **无移动 App**：当前为 Web，App 为远期目标。
