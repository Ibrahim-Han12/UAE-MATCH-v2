## 1. 代码与配置

- [ ] **JWT 密钥已更换**
  通过标准：`JWT_SECRET_KEY` 与 `JWT_REFRESH_SECRET_KEY` 均非默认值 `change-this-in-production`，为 ≥64 位随机串，且两者不同，仅存于环境变量。
- [ ] **OpenAI Key 已轮换并走环境变量**
  通过标准：生成全新 `OPENAI_API_KEY`，旧 Key 在 OpenAI 后台已吊销；密钥不出现在代码/git 历史，仅在 `backend/.env` 或密钥管理系统。
- [ ] **DEBUG 已关闭**
  通过标准：生产 `DEBUG=false`；接口错误不返回堆栈；API 文档（/docs）按策略关闭或加访问控制。
- [ ] **CORS 已收紧**
  通过标准：`main.py`/`CORS_ORIGINS` 只含正式前端域名，不含 `*`、不含 localhost；协议为 https。
- [ ] **支付密钥/回调验签配置就绪**
  通过标准：支付宝/微信密钥走环境变量；`POST /api/v1/payment/callback` 已启用签名校验，拒绝伪造回调。
- [ ] **敏感信息无硬编码**
  通过标准：全仓检索无明文密钥/口令；`.env` 已 gitignore 且未进入 git 历史。
- [ ] **前端 API 地址正确**
  通过标准：`VITE_API_BASE_URL` 指向 `https://api.<域名>/api/v1`，且已重新 `npm run build` 生效。
- [ ] **通知系统状态确认**
  通过标准：`/notifications/*` 当前为桩实现，已确认 v1.0 范围是否可接受（不可接受则须补齐）。

## 2. 基础设施

- [ ] **HTTPS 已启用并强制**
  通过标准：正式证书有效、未过期；http 自动 301 跳 https；TLS 1.2+。
- [ ] **域名与 DNS 就绪**
  通过标准：前端域名、`api.` 后端域名解析正确，TTL 合理，CDN 域名可达。
- [ ] **数据库已迁 PostgreSQL + pgvector**
  通过标准：生产用 PG；`CREATE EXTENSION vector` 已装；20 张表齐全；行数与迁移源一致；HNSW 索引已建。
- [ ] **Alembic 迁移已就位**
  通过标准：`alembic upgrade head` 可执行且与线上表结构一致；不再依赖手写 `migrate_add_*.py`。
- [ ] **Redis 就绪**
  通过标准：`redis-cli ping` 返回 PONG；缓存/限流已接入；持久化与内存上限配置合理。
- [ ] **照片对象存储 + CDN 就绪**
  通过标准：上传写入对象存储；历史照片已迁移并回填 `user_photos.file_url`；CDN 可访问。
- [ ] **备份策略已启用**
  通过标准：数据库每日全量备份、保留期已定；已完成一次**恢复演练**；对象存储开启版本控制。
- [ ] **定时任务多实例安全**
  通过标准：缓存清理/VIP 关怀仅由单一调度节点执行（`ENABLE_SCHEDULER` 或独立 cron/锁），确认不会重复。
- [ ] **反向代理与 WebSocket 配置正确**
  通过标准：Nginx `/api/` 与 `/ws/` 均可用；WebSocket `Upgrade` 头正确，聊天长连接稳定。

## 3. 安全

- [ ] **API 限流已启用**
  通过标准：聊天发送（10 秒 ≤20 条）、`/coach/match-insights`（30 次/分）等限流生效；建议网关层加全局限流。
- [ ] **内容审核生效**
  通过标准：`safety.detect_content_risk` 关键词/正则审核在聊天链路生效；BLOCKED/HIGH 被拦截并记 `content_blocked` 事件。
- [ ] **依赖漏洞扫描通过**
  通过标准：`pip-audit`（后端）、`npm audit`（前端）无高危未修复项；已升级或记录豁免。
- [ ] **鉴权覆盖正确**
  通过标准：需鉴权接口全部校验 Bearer token；仅 health/register/login/refresh/payment callback/products/photos file 等按设计免鉴权。
- [ ] **管理员接口受控**
  通过标准：`/admin/*` 仅 `is_admin` 用户可访问，已验证越权被拒。
- [ ] **上传校验生效**
  通过标准：`/photos/upload` 限 JPEG/PNG/WebP、≤10MB、≤9 张，非法文件被拒。
- [ ] **日志不含敏感信息**
  通过标准：日志无明文密码、token、OpenAI Key、支付密钥。

## 5. 功能验证（生产/预发冒烟）

- [ ] **注册 / 登录**
  通过标准：邮箱或手机注册成功；登录返回 access+refresh；refresh 换新 access 正常；`/auth/me` 正确。
- [ ] **资料 / 偏好 / 照片**
  通过标准：`PUT /profile/me`、`PUT /preferences/me` 保存生效；照片上传/设主图/删除正常。
- [ ] **匹配**
  通过标准：规则匹配 `/matches/suggestions` 返回候选；双方 like 触发互相匹配（`is_mutual_match`）并建 `match_pairs`。
- [ ] **AI 向量匹配**
  通过标准：`POST /match/recommend` 返回 Top 候选与推荐理由；配额（普通 2 次/月、VIP 10 次/月）与全局预算约束生效。
- [ ] **聊天（REST + WebSocket）**
  通过标准：发送/接收消息落库；WebSocket 实时推送；违规内容被拦截；限流生效。
- [ ] **支付回调**
  通过标准：下单返回 payment_url；`/payment/callback` 验签通过后正确更新订单与订阅状态；订阅状态查询正确。
- [ ] **AI 功能（红娘/记忆/关怀/分析）**
  通过标准：`/ai-chat/send-message` 正常且更新记忆；`/coach/match-insights` 生成分析并命中 30 天缓存；VIP 关怀可触发。
- [ ] **健康检查**
  通过标准：`GET /api/v1/health` 返回 `{"status":"ok"}`。
