## 0. 为什么需要这份设计（承认缺口）

**已有的 AI 设计**（基础设施层，✓ 已落地）：模型抽象层与计量、三层记忆双轨、深访三层配置分离（Schema 层 / 问法库层 / 人格层）、匹配算法。

**缺失的**：**对话行为层**的系统设计。现状是"人格基线 + 每轮注入指令 + 关键词正则"的补丁堆，四轮真人测试暴露的 9 个问题（预设婚史/无视纠正/复读/背景当发言/定位跑偏/不尊重停止/无出口/前进当停止/自作主张收尾）全部源于此。**症状的共性：没有意图理解、没有对话流程结构、没有输出防御、没有回归测试。**

**实测数据佐证结构性缺陷**：13 轮完成 52%——A/B 类事实（自由聊可采）全收齐，C 类（结构化择偶条件）与 D 类（情境题行为编码）颗粒无收：不同类别字段需要**不同交互模式**，现编排器只有一种。

**定位**：本设计是小缘所有对话场景的通用架构。M2 先落深访；M3 军师（能力分层 L2）与主动触达（L3）复用同一套层次。

## 1. 分层架构（对话一轮的完整通路）

```
用户消息
  ↓
[意图层]      每轮分类：answer / correction / refusal_field(拒答某题)
              / stop(想停) / proceed(想前进) / ask_ai(反问小缘) / smalltalk / crisis
              — mini 模型结构化输出；危机关键词作硬规则前置兜底（不依赖分类）
  ↓
[会话状态机]  会话级：深访 = 幕状态机（§3），状态持久化、跨天恢复
  ↓
[幕策略]      每幕独立 policy：问什么、怎么问、何时切幕、该幕专属抽取契约（§4）
  ↓
[生成]        分层 prompt 装配：[人格层] + [幕策略] + [轮指令(意图路由结果)] + [已知事实(标注为背景)]
  ↓
[输出校验]    纯代码校验：①无收尾指令必须含提问 ②开头与上轮不重复 ③不含结束语禁词
              不合格 → 重生成 1 次 → 仍不合格放行 + 记 quality_event（§5）
  ↓
回复用户 + 分幕抽取落库 + 状态更新
```

关键转变：**把"希望 LLM 听话"变成"结构上让它只能听话"**——意图先于生成、流程先于问法、校验后于生成。

## 2. 意图层

- 每轮一次 mini 调用（结构化 JSON：intent + 置信度 + 目标字段号若是拒答/纠正），约 +0.0002 USD/轮。
- **意图 → 策略路由表**（取代关键词 if-else）：

| 意图 | 路由 |
|---|---|
| answer | 正常流：抽取 → 下一问 |
| correction | 先确认更正 → 覆写字段（stated）→ 继续 |
| refusal_field | 该字段标记 declined（换一种问法重试过一次后不再问；PRD 5.5：说明影响不阻塞）→ 跳下一字段 |
| stop | 收尾流（现有 STOP 指令保留） |
| proceed | 进度答复流（现有 PROCEED 指令保留） |
| ask_ai | 先答用户的问题，再回到当前幕 |
| smalltalk | 短回应 + 顺势回到当前幕 |
| crisis | 固定话术流（硬规则前置，已有） |

- 现有关键词表降级为 crisis 兜底与分类失败 fallback。
- **refusal_field 是新增关键能力**：现在"拒答"没有字段级处理，导致必采字段永远追着问或永远缺失。拒答字段计入完成度豁免（declined 视为"已处理"，DEC-028），但推荐引擎按缺失降置信度（算法 §4.6 已支持）。
- **地板线约束（DEC-033，✅ 已裁决）**：`C1` 对方年龄范围 / `C5` 免谈项清单 / `B3` 子女计划 三项**不允许 declined**——首次拒答换问法重试一次，仍拒则明确告知"这项不填没法推荐"，**完成度卡住不推进**（不写 declined）。其余 22 项必采维持 DEC-028 逻辑（重试一次 → 标 declined → 视为已处理）。落为 refusal_field 路由的例外分支：`FLOOR_FIELDS = {C1, C5, B3}`。

## 3. 会话状态机（深访实例）

```
opening(价值先行+授权) → act1_facts(A+B类,自由对话) → act2_criteria(C类,快问快答)
→ act3_scenarios(D类,情境题) → closing(报告+速写确认)
```

| 幕 | 字段集 | 交互模式 | 进入话术要点 | 退出条件 |
|---|---|---|---|---|
| act1 | A4-A10, B1-B6 | 自由对话（现状，已验证 13 轮收齐） | 现有开场 | A+B 必采全部 filled/declined |
| act2 | C1-C5 | **明示环节**（"接下来是最关键的择偶条件，几分钟就好"），逐项快问 + post_step 弹性确认 | 里程碑感："基础了解完成 ✓" | C 类全部 filled/declined |
| act3 | D1-D4 | **情境题模式**：问法库 scenario 原题稍作语境化，一题一答 | "最后几个轻松的小情景" | D 类全部 filled/declined |

- 新表 `interview_state`（DEC-032）：user_id、current_act、act_entered_at、declined_fields JSON、updated_at。跨会话恢复读此表。
- 幕内目标顺序 = Schema 顺序；用户跑题聊到其他幕字段照常顺势采集（不切幕）。
- 前端进度条按幕分段显示（act1/2/3 三段）。
- **已知风险（act2 与 DEC-029 对立）**：act2 的逐项快问是所有交互模式里最像表单的一种，会加重实测反馈的"客服腔/很呆"。缓解：act2 每项先给一句针对上一答的具体反应再问下一项，弹性确认本身作为有信息量的追问而非机械确认。根治仍依赖人格层资产（DEC-018）。

## 4. 抽取契约分幕（命中率与成本双改善）

- **act-scoped targets**：每轮只抽当前幕字段 + 上一幕补漏，而非全 Schema 25+ 项（现状每轮全量→prompt 长、命中散）。
- **D 类抽取注入 coding_rubric**：问法库里已有编码规则（secure/anxious/avoidant 的行为特征），现在抽取 prompt 根本没带——这是 D 类颗粒无收的第二根因。act3 的抽取契约 = 当题字段 + 该题 rubric + "按行为编码，不确定输出 unclear"。
- act3 结果默认 inferred；同维度第二个情境交叉一致后升 stated（Schema G5 语义）。

## 5. 输出校验层（纯代码，零成本）

| # | 规则 | 处置 |
|---|---|---|
| V1 | 无【收尾指令】时回复必须含"？/?" | 重生成 1 次，携带违规说明 |
| V2 | 回复前 8 字与上一轮小缘回复前 8 字相同 | 重生成 1 次 |
| V3 | 无收尾指令时含结束语禁词（"今天聊到这里/随时欢迎再来/期待下次"） | 重生成 1 次 |
| — | 重生成仍违规 → 放行 + `quality_event` 埋点 | 供回归与人工审 |

> V1 的例外：意图层判定为 crisis 或 ask_ai 时不强制含提问（危机话术与答用户问题不应被追问污染）。

## 6. 质量评估体系（给 AI 建"测试"）

- **黄金对话集**：把四轮真人测试的 9 个问题场景固化为回归用例（用户消息序列 + 行为断言：意图分类正确/不追问/含提问/切幕正确……不逐字断言生成文本）。
- **回放 harness**：`scripts/eval_dialogue.py`——mock 网关跑意图/状态机/校验器断言（零成本），真实模型抽样跑生成质量（可选、少量）。
- **纪律**：改人格层/问法库/幕策略 → 必须先过回归集再提交（等同代码测试）。
- 线上指标（埋点已有底座）：深访完成率（目标 ≥70%，PRD）、轮数分布、每轮推进率、拒答率、幕停留时长、quality_event 率。

## 7. 人格层资产（DEC-018）

人格与风格文案 = `backend/config/persona/` 下的人格层资产（分幕子模板：opening/act1/act2/act3/closing 的语气示例）。本设计**不含人格内容**——那是产品资产；架构保证 DEC-018 到位时整体替换、零代码改动。

## 8. 实施切片

| 切片 | 内容 | 定位 |
|---|---|---|
| **SL1（MVP 阻塞，先做）** | 会话状态机（幕）+ act2/act3 交互模式 + D 类 rubric 注入抽取 + 输出校验 V1-V3 + refusal_field 字段级拒答 | 让漏斗**可完成**——这是 MVP 的一部分 |
| SL2 | 意图层替换关键词路由 | 根治"关键词误判"类 bug |
| SL3 | 评估 harness + 黄金对话集 + 回归纪律 | AI 的持续质量保障 |
| 后置（MVP 后） | 人格层终稿接入（DEC-018）、军师对话（能力分层 L2）复用本架构、线上指标看板 | 质感与扩展 |

**切片顺序裁决（2026-08-22）：意图层并入 SL1。** 理由：SL1 含 refusal_field（字段级拒答），而"用户在拒答"本身就是意图判断；按原排法 SL1 只能再用一遍关键词正则，SL2 再拆掉重写——即 SL1 建在本设计自己诊断为坏地基的东西上。DEC-033 的地板线更强化了这一点：要区分"这是拒答"与"这是在答别的"，关键词判不准。意图层成本仅 +0.05 AED/场（DEC-031）。

SL1 落地范围因此变为：意图层 + 幕状态机 + act2/act3 交互模式 + D 类 rubric 注入抽取 + 字段级拒答（含 DEC-033 地板线）。**输出校验层已于 2026-08-22 单独落地**（commit 4688a90，随人格资产 v1.1 一并上线），不在 SL1 剩余范围内。
